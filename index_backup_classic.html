FAQ

Häufige Fragen

Wie lange dauert die Umsetzung einer Website?
Die Umsetzung dauert in der Regel zwei bis vier Wochen, je nach Umfang und gewünschten Funktionen (wie z. B. Schnittstellenanbindungen).
Binden Sie bestehende Maklersoftware wie onOffice oder Propstack an?
Ja. Ihre Objekte werden vollautomatisch über eine standardisierte OpenImmo-Schnittstelle oder direkte REST-APIs synchronisiert, sodass Sie Objektdaten nur an einer einzigen Stelle pflegen müssen.
Ist die Website rechtssicher (DSGVO)?
Absolut. Ich verzichte auf externe Schriftarten (Google Fonts werden lokal gehostet), betreibe datenschutzkonformes Hosting und binde ein rechtssicheres Impressum und eine Datenschutzerklärung ein.
Gibt es laufende monatliche Kosten oder eine Mindestlaufzeit?
Nein. Bei CÉ Studios zahlen Sie einen einmaligen Festpreis. Der Code und das Hosting gehören vollständig Ihnen. Es gibt keine monatlichen Fesseln oder versteckten Gebühren.
